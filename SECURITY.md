## Prijava ranljivosti / Reporting a vulnerability

**SL :** Odkrijete li varnostno ranljivost ( skrivnost, žeton, ključ, vbrizg ), je poročanje vrata, ⟨ne⟩ obup :
1. **GitHub Security Advisory** — zasebno poročilo na tem repu ( Security → Report a vulnerability ) — najhitrejša steza ⊢.
2. **Zasebni kanal** — ⟡ ( Luka Pintarič ) prejme poročilo po zasebni poti; poročilo ⟨ne⟩ potuje po javnih kanalih.
3. **⟨NE⟩ javna objava pred zaprtjem** — ranljivost, odkrita javno, se kurira po dogovoru; javna vrata ostanejo vrata ( prijava, ⟨ne⟩ obsodba ⊙ §0.4 × 10¹ ).

**EN :** If you discover a security vulnerability ( secret, token, key, injection ), reporting is welcome and private :
1. **GitHub Security Advisory** on this repository ( Security → Report a vulnerability ) — fastest route.
2. **Private message** to the maintainer.
3. **Do not** open a public issue with exploitable detail before the fix is sealed.
